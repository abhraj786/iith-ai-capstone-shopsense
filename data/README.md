# Data placement

This starter contains placeholder folders for all five domains; use only your selected domain.
Generated corpus, intake, table and golden-set files are NOT included. Generate them with
https://github.com/AI-Launchpad-Dev/data-toolkit or copy a completed domain folder here.

Keep generated source data unchanged. Store derived chunks under `processed/<domain>/`.
Keep approved public datasets under `external/<dataset>/` with source/licence records.
Do not put golden answers, intake ground truth or private interaction memory in the corpus.
All generated data and runtime contents are ignored by Git; these README/.gitkeep files remain tracked.
See the root README for commands and expected outputs.
