# ShopSense Data

This repository keeps only the ShopSense data required to run the current capstone implementation.

- `shopsense/intake/records.jsonl`: raw customer intake messages with ground-truth labels for evaluation
- `shopsense/mock_api/`: generated policy and mock API tables used by deterministic tests and M1 escalation policy checks
- `shopsense/manifest.json`: generation metadata

Other capstone domains are intentionally not included in this repository.
